# Report package

`CS324_A2_Report.docx` is generated by `build_report.py` using `python-docx`, so
the Word file can be rebuilt after the group fills in the highlighted fields.

## Placeholders to replace

- Group number / tutorial group on the title page.
- Four member names and student IDs in the contribution table.
- Four contribution percentages; they must sum to 100%.
- Meeting dates, attendees and action owners in Appendix C.

All placeholders are highlighted yellow by the generator.

## Rebuild

From the repository root:

```powershell
python report\build_report.py
```

The script reads `report/git-log.txt`, which is generated with:

```text
git log --graph --date=short --pretty=format:'%h %ad %an%x09%s' --all
```

Q1-Q5 use 12-pt body text and start on new pages. Appendix A uses a smaller
monospace font for the Git log; appendices are not part of the two-page limit
for each question.
